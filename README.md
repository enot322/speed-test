# Тестовое задание: Замер скорости интернета

Консольный скрипт на Node.js для замера скорости скачивания данных по указанному URL.

## Требования
- Node.js версии **18.0.0 или выше** (используется встроенный `fetch`, сторонние библиотеки не нужны).

## Инструкция по запуску

Скрипт принимает URL-адрес в качестве аргумента командной строки. 
Для теста отлично подходит сервис Cloudflare, который отдает ровно 10 МБ данных:

```bash
node index.js "https://speed.cloudflare.com/__down?bytes=10000000"
